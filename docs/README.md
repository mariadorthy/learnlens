# LearnLens — Project Documentation

**LearnLens — From Learning to Proof of Understanding**

This directory contains the technical and project documentation for **LearnLens**, an AI-enabled adaptive learning and learning-verification platform developed for **Prasunethon 2.0 — Round 2** by **Team Tech Nova**.

The documentation covers the project's problem, solution, core features, system architecture, testing, and deployment.

## Core LearnLens Concept

The documentation is built around the central LearnLens idea:

```text
Attempt
   ↓
Evidence
   ↓
Understanding
   ↓
Adaptive Action
   ↓
Proof-of-Learn
```

The **Knowledge Fingerprint** represents understanding across:

```text
Recall → Explain → Predict → Implement → Debug → Apply
```

---

## Documentation Principle

All documentation is intended to remain aligned with the **actual implemented MVP**.

Advanced capabilities that are not currently implemented are described as **future scope** rather than existing functionality.

---

## Project Scope

LearnLens focuses on:

**Learning → Assessment → Evidence → Understanding Profile → Verification → Adaptation**

The goal is to move beyond simple lesson completion and quiz scores toward **evidence-based verification of understanding**.
